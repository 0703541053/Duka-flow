# DukaFlow

A lightweight order and inventory dashboard prototype for Kenyan small shops that sell through WhatsApp or Instagram.

## Run locally

Open `index.html` in a modern browser. No build step or package installation is required.

## Prototype scope

- View a sample shop dashboard, recent orders, and low-stock products.
- Add products and track stock in the Products view.
- Create orders, update order status, and automatically deduct ordered stock.
- Prepare an order message in WhatsApp when a customer phone number is available.
- Save prototype data in the current browser using local storage.

This is a front-end prototype: data stays in one browser on one device, the shop profile is sample content, and WhatsApp sharing opens a prefilled message rather than sending it automatically. It does not yet include accounts, cloud sync, payments, backups, or multi-user access. Do not use it as the sole record of real orders or customer data.
